## Hi, I'm cuherayk! 👋

I build small web tools — TypeScript on the front, Python and FastAPI behind it, with SQLite quietly doing the unglamorous work underneath. Most of what I make starts from the same question: how much can you take away before a tool stops being useful? That curiosity tends to turn into micro-SaaS side projects and tiny developer utilities that exist mostly because something annoyed me for a week.
